# GIT

## 0. (git init) helps to initialize a project with git
## 1. (git add .) helps to add our project to git, it tells git to track our progress.
## 2. (git commit -m"Commit message") helps to add commit message to our git commit, so we know what updates that we make.
## 3. (git push) helps to upload our updates to github, it also helps to upload our updates to an exisiting project
## 4. (git clone repo_ssh_url) helps to download a project to our computer
## 5. (git status) git status helps to check if we have a project we are tracking or not, if you get a red colored text then that file or folder is not tracked by git, if you get a green colored text then it means that what ever you are working on is tracked by git
## 6. (git pull) git pull helps to pull updates that was made by a contributor
